### 基础模型

### 1. `int x` 是值传递
- 它将函数参数的**值**复制一份传入函数。
- 函数内部对 `x` 的修改不会影响函数外部的变量。
- 示例：
  ```cpp
  void func(int x) {
      x = 10;
  }

  int main() {
      int a = 5;
      func(a);
      cout << a; // 输出 5
  }
  ```

### 2. `int& x` 是引用传递
- 它将函数参数的**引用**传入函数。
- 函数内部对 `x` 的修改会直接影响函数外部的变量。
- 示例：
  ```cpp
  void func(int& x) {
      x = 10;
  }

  int main() {
      int a = 5;
      func(a);
      cout << a; // 输出 10
  }
  ```

Java 的 final 引用是不是表示对象完全不能修改？

### 检查要点

- 给简短例子

### 基础模型

不是的，Java 中的 `final` 关键字用于引用时，表示**引用本身不能被修改**，而不是对象本身不能被修改。

### 举个例子说明：

```java
final Person p = new Person("Alice");
```

- `p` 是一个 `final` 引用，意味着你不能将 `p` 指向另一个对象（例如 `p = new Person("Bob");` 会报错）。
- 但 `p` 所指向的对象（即 `Person` 实例）的内容是可以被修改的，只要该对象的属性不是 `final`。

### 示例代码：

```java
class Person {
    String name;

    Person(String name) {
        this.name = name;
    }
}

public class Main {
    public static void main(String[] args) {
        final Person p = new Person("Alice");
        p.name = "Bob"; // ✅ 允许修改对象的属性
        // p = new Person("Charlie"); // ❌ 不允许修改引用
    }
}
```

### 总结：
- `final` 引用不能指向新的对象。
- 但对象内部的状态（非 `final` 的属性）仍然可以被修改。

你是否想了解 `final` 修饰类、方法或变量时的区别？

### LoRA

不是的，Java 中的 `final` 关键字用于引用时，表示**引用本身不能被修改**，而不是对象本身不能被修改。

### 举个例子说明：

```java

```

- `obj` 是一个 `final` 引用，意味着你不能将 `obj` 指向另一个对象（比如 `obj = new MyClass();` 会报错）。
- 但是，`obj` 所指向的对象内部的字段仍然可以被修改，只要这些字段不是 `final` 的。

### 示例代码：

```java

    public int value = 10;
}

public class Main {
    public static void main(String[] args) {

        System.out.println(obj.value); // 输出 20
    }
}
```

### 总结：
- `final` 引用不能指向其他对象。
- 对象内部的字段可以被修改（除非字段也是 `final`）。


### 修正方法

```cpp
int count = 0;
count += 1;
std::cout << count;  // 输出 1
```

```cpp
    }
```

```java
}
```

### 实现思路
1. **输入一个正整数 n**。
2. **初始化一个变量 result 为 1**。
3. **从 1 到 n 循环相乘**。
4. **输出结果**。

### 参考代码（Python）
```python
n = int(input("请输入一个正整数: "))
result = 1
for i in range(1, n + 1):
    result *= i
print(f"{n}! = {result}")
```

- `range(1, n + 1)` 确保循环包括 n。

### 📌 阶乘的定义
阶乘是指一个正整数 $ n $ 的阶乘，记作 $ n! $，定义为：
$$
n! = n \times (n-1) \times (n-2) \times \cdots \times 1
$$
例如：
- $ 5! = 5 \times 4 \times 3 \times 2 \times 1 = 120 $

### ✅ 参考实现（Python）

```python
def factorial(n):
    # 处理特殊情况：n < 0
    if n < 0:
        return "错误：阶乘仅对非负整数定义"
    # 处理 n = 0 或 n = 1 的情况
    if n == 0 or n == 1:
        return 1
    # 使用循环计算阶乘
    result = 1
    for i in range(2, n + 1):
        result *= i
    return result

# 示例调用

print(factorial(0))  # 输出: 1
```
